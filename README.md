# IntelliPrep - AI Interview Practice Platform

An intelligent interview practice platform powered by Ollama LLM. Practice with realistic AI-generated interview questions tailored to your target role.

## Features

- 🤖 **AI-Powered Interviews** - Realistic questions generated by Ollama LLM
- 📝 **Resume Management** - Store and manage multiple resume versions
- 🎯 **Role-Specific Questions** - Questions tailored to your target position
- 🎙️ **Voice Integration** - Text-to-speech for interview questions
- 📊 **Interview Transcripts** - Track your responses with live transcripts
- 💾 **Local Storage** - All data stored locally in your browser (IndexedDB)

## Tech Stack

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Backend**: Node.js + Express
- **AI Engine**: Ollama (llama3.1)
- **Database**: IndexedDB (browser), JSON files (server)

## Prerequisites

- Node.js 18+
- Ollama with llama3.1 model installed
- npm or yarn

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Sujithashree/Intelliprep.git
cd Intelliprep
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env
```

4. Make sure Ollama is running:
```bash
ollama serve
```

5. In another terminal, pull the model (if not already done):
```bash
ollama pull llama3.1
```

## Running the Application

Start the server:
```bash
npm start
```

The application will be available at `http://localhost:3000`

For development with auto-reload:
```bash
npm run dev
```

## Configuration

Edit `.env` file to customize:
- `PORT` - Server port (default: 3000)
- `HOST` - Server host (default: localhost)
- `OLLAMA_BASE_URL` - Ollama API URL (default: http://localhost:11434/v1)
- `OLLAMA_MODEL` - Model name (default: llama3.1)
- `OLLAMA_API_KEY` - Ollama API key (default: ollama)

## Usage

1. **Add Your Resume** - Upload PDF, DOC, or DOCX files
2. **Select Active Resume** - Choose which resume to use
3. **Enter Role Details** - Target role and job description
4. **Start Interview** - Click "Start interview" to begin
5. **Practice & Improve** - Answer questions and track your performance

## API Endpoints

### Interviews
- `GET /api/interviews` - Get all interviews
- `GET /api/interviews/:id` - Get specific interview
- `POST /api/interviews` - Create new interview

### AI Interview
- `POST /api/ai/interview` - Generate questions and evaluations

### Resumes
- `GET /api/resumes` - Get all resumes
- `GET /api/resumes/:id` - Get specific resume
- `POST /api/resumes` - Upload resume
- `DELETE /api/resumes/:id` - Delete resume

## Troubleshooting

### No audio playback
- Check browser Web Speech API: Open DevTools console
- Ensure TTS voices are installed on your system
- Try different browser (Chrome/Edge recommended)

### Ollama connection error
- Verify Ollama is running: `curl http://localhost:11434/api/tags`
- Check `OLLAMA_BASE_URL` in `.env`
- Ensure llama3.1 model is installed

### Missing questions
- Check server logs for AI errors
- Ensure job description is detailed enough
- Verify Ollama model is loaded
