# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-01

### Added
- Initial release of IntelliPrep
- AI-powered interview question generation using Ollama LLM
- Resume upload and management (PDF, DOC, DOCX)
- Role-specific interview questions
- Live interview transcript tracking
- Voice synthesis for interview questions
- Local storage using IndexedDB
- Interview history and tracking
- Responsive UI with modern design

### Features
- Intelligent question generation based on role and job description
- Multiple resume support with easy switching
- Real-time interview transcripts
- Voice playback for questions
- Interview scoring system (ready for evaluation)
- Data persistence across sessions
- Mobile-responsive design

### Technical
- Built with vanilla JavaScript
- Express.js backend
- Ollama integration for AI
- IndexedDB for client-side storage
- RESTful API architecture

### Known Issues
- Text-to-speech voices may need system configuration on some macOS systems
- Browser compatibility varies for Web Speech API
